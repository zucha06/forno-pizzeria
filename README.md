# FORNO — Pizza & More

An example, responsive pizzeria website created in HTML, CSS, and pure JavaScript.

## Launch
Open `pizzeria.html` in your browser. No dependencies or server installation required.

## Features
- Responsive layout on desktop and mobile
- Menu with category filtering
- Shopping cart with adding/removing products and price summary
- Mobile navigation
- Sections: hero, menu, history, CTA, and contact

This is a demo project for a portfolio. The shopping cart does not send real orders.
